What is ML · supervised vs unsupervised

S1–S2
WhatMachine ko rules haath se nahi likhte; data se pattern seekhne dete hain. Program experience (data) se task pe better hota jaata hai.
WhyKuch problems ke rules likhna impossible hai (kaunsa student risk pe hai?). Data mein pattern hai, model use pakad leta hai. Exam mein 5-mark "define + types + examples" pakka aata hai.
When"Define ML", "differentiate supervised and unsupervised", "classify these tasks" type wording.
HowLabel hai? → supervised (number = regression, category = classification). Label nahi? → unsupervised (clustering, dimensionality reduction, density estimation).
A computer program is said to learn from experience \(E\) with respect to some class of tasks \(T\) and performance measure \(P\), if its performance at tasks in \(T\), as measured by \(P\), improves with experience \(E\) (Mitchell). In supervised learning the training data are input–target pairs \(\{(\mathbf{x}_n, t_n)\}_{n=1}^{N}\) and the goal is to predict \(t\) for a new \(\mathbf{x}\); in unsupervised learning only the inputs \(\{\mathbf{x}_n\}\) are given and the goal is to discover structure such as clusters, low-dimensional representations or the density \(p(\mathbf{x})\).
AspectSupervisedUnsupervised
Data\((\mathbf{x}, t)\) pairs, labelledonly \(\mathbf{x}\), unlabelled
Goalpredict \(t\) for unseen \(\mathbf{x}\)find structure / compress / model \(p(\mathbf{x})\)
Tasksregression (\(t \in \mathbb{R}\)), classification (\(t \in \{1,\dots,K\}\))clustering, dimensionality reduction, density estimation
Algorithms (this course)linear regression, logistic, LDA, SVM, CARTK-Means, GMM + EM, hierarchical, PCA, factor analysis
Evaluationaccuracy, F1, ROC-AUC, RMSE, \(R^2\) on held-out datasilhouette, Davies–Bouldin, BIC, likelihood, ARI (if labels exist)
Both types on the same data. Supervised: predict at_risk (classification, CV AUC 0.953) and end-semester SGPA (regression, \(R^2 = 0.798\)). Unsupervised: K-Means finds 3 personas (High risk / Coasting / Engaged achievers) without ever seeing the label. The HMM in Unit 4 is unsupervised too: hidden states are never labelled.
"Generalisation" means performance on unseen data, not training data. A model with 100 % training accuracy can still be useless (overfitting, topic 02).

Polynomial curve fitting · overfitting · regularisation

S3 · B1 §1.1
WhatPoints ke beech ek polynomial curve fit karna: \(y(x,\mathbf{w}) = w_0 + w_1x + \dots + w_Mx^M\). \(M\) = order (flexibility).
WhyYe ML ka "hello world" hai: underfitting vs overfitting aur regularisation yahin samajh aata hai. Har unit isi idea pe wapas aata hai.
When"Explain overfitting with polynomial curve fitting", "role of \(M\) / \(\lambda\) / data size", "sum-of-squares error".
How\(E(\mathbf{w}) = \tfrac12\sum_n (y(x_n,\mathbf{w}) - t_n)^2\) minimise karo (linear in \(\mathbf{w}\) → closed form). \(M\) badhao to train error ↓, test error pehle ↓ phir ↑.
Polynomial curve fitting models \(y(x,\mathbf{w}) = \sum_{j=0}^{M} w_j x^j\), which is nonlinear in \(x\) but linear in \(\mathbf{w}\), and chooses \(\mathbf{w}\) by minimising the sum-of-squares error \[E(\mathbf{w}) = \frac{1}{2}\sum_{n=1}^{N}\big\{y(x_n,\mathbf{w}) - t_n\big\}^2 .\] A model that fits the training data closely but generalises poorly is overfitting; it is controlled by more data, a lower order \(M\), or regularisation \(\widetilde{E}(\mathbf{w}) = E(\mathbf{w}) + \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2\), which penalises large coefficients.

W2 · Why does a \(9\)th-order polynomial through \(10\) points have zero training error but huge test error?

Show solution
A polynomial of order \(M\) has \(M+1 = 10\) free coefficients \(w_0,\dots,w_9\).count parameters

03

Probability rules · Bayes' theorem · independence

S4–S5 · B2 §2.2
WhatDo hi rules: sum rule \(p(X) = \sum_Y p(X,Y)\) aur product rule \(p(X,Y) = p(Y\mid X)\,p(X)\). Bayes inhi dono se nikalta hai.
WhyHar probabilistic model (NB, LDA, GMM, HMM) inhi do rules pe chalta hai. 5-mark "state and derive Bayes" + 10-mark numerical common hai.
When"Given prior and likelihood find posterior", "test is 90 % accurate…", "are A and B independent?", "conditional independence".
HowPosterior = likelihood × prior / evidence. Evidence \(= \sum_h P(E\mid h)P(h)\). Independence check: \(P(A\cap B) \overset{?}{=} P(A)P(B)\).
Bayes' theorem: \[P(H\mid E) = \frac{P(E\mid H)\,P(H)}{P(E)}, \qquad P(E) = \sum_{h} P(E\mid h)\,P(h),\] where \(P(H)\) is the prior, \(P(E\mid H)\) the likelihood, \(P(E)\) the evidence and \(P(H\mid E)\) the posterior. Events \(A\) and \(B\) are independent if \(P(A,B) = P(A)P(B)\); they are conditionally independent given \(C\) if \(P(A,B\mid C) = P(A\mid C)\,P(B\mid C)\).

\(P(E\mid H) \neq P(H\mid E)\). "90 % of at-risk students have low attendance" does not mean "90 % of low-attendance students are at risk". The prior (base rate) changes everything.
Naive Bayes = features conditionally independent given the class: \(p(x_1,\dots,x_D\mid C) = \prod_{i=1}^{D} p(x_i\mid C)\). Galat assumption bhi often achha classifier deta hai.
\(H\) = at risk, \(E_1\) = attendance below SRM's 75 % rule, \(E_2\) = internals below 60 %. Prior 0.28 → after \(E_1\) 0.71 → after \(E_2\) 0.96. Exact \(P(H\mid E_1,E_2)\) from data is 0.963, so assuming \(E_1 \perp E_2 \mid H\) costs only 0.002 here. Low attendance and low study hours are dependent overall (\(P(A\cap B) = 0.175\) vs \(P(A)P(B) = 0.117\)) but much closer to independent once risk is known: risk is the common cause.

04

Continuous RVs · quantiles · mean, variance · expectation · covariance

S6–S7 · B2 §2.2, B1 §1.2
WhatContinuous variable (CGPA, attendance) ke liye probability density \(p(x)\); \(P(a\lt X\lt b) = \int_a^b p(x)\,dx\). Quantile = CDF ka inverse.
WhyGaussian har jagah hai: regression noise, LDA, GMM, Kalman. Mean, variance, covariance = EDA ki language (PBL-I ke 4 marks).
When"Find expectation and variance", "compute covariance / correlation", "median / quartiles", "probability from a normal distribution".
How\(\mathbb{E}[X] = \sum x\,p(x)\) or \(\int x\,p(x)\,dx\); \(\operatorname{var}[X] = \mathbb{E}[X^2] - \mathbb{E}[X]^2\); \(r = \dfrac{\operatorname{cov}[X,Y]}{\sigma_X\sigma_Y}\).
For a continuous random variable \(X\) with probability density \(p(x) \ge 0\), \(\int p(x)\,dx = 1\), the cumulative distribution is \(F(x) = P(X \le x)\) and the \(q\)-quantile is \(F^{-1}(q)\) (median \(= F^{-1}(0.5)\)). The expectation of \(f\) is \(\mathbb{E}[f] = \int p(x) f(x)\,dx\), the variance is \(\operatorname{var}[x] = \mathbb{E}[x^2] - \mathbb{E}[x]^2\), and the covariance is \[\operatorname{cov}[x,y] = \mathbb{E}\big[(x - \mathbb{E}[x])(y - \mathbb{E}[y])\big], \qquad r = \frac{\operatorname{cov}[x,y]}{\sigma_x\sigma_y} \in [-1, 1].\] The Gaussian density is \(\mathcal{N}(x\mid\mu,\sigma^2) = \dfrac{1}{\sqrt{2\pi\sigma^2}}\exp\!\Big\{-\dfrac{(x-\mu)^2}{2\sigma^2}\Big\}\).
CGPA in the cohort, modelled as \(\mathcal{N}(7.32,\,1.34^2)\). Shaded: \(P(\text{CGPA} \lt 6) = 0.161\) under the normal model; the data say 0.215 (left tail heavier than Gaussian).
Correlation sirf linear relation pakadta hai. \(r \approx 0\) ka matlab "no relation" nahi, sirf "no linear relation". Aur \(r\) scale-free hai, covariance nahi.
Sample variance/covariance mein \(N-1\) se divide karo (unbiased): \(s^2 = \frac{1}{N-1}\sum (x_n-\bar x)^2\). Sirf population formula pucha ho to \(N\).
EDA (PBL-I rubric 4 marks): CGPA mean 7.32, variance 1.79, quartiles 6.24 / 7.31 / 8.45. Strongest correlation with at_risk: internal marks \(r = -0.67\), attendance \(-0.59\), backlogs \(+0.41\). Attendance ↔ internals: \(\operatorname{cov} = 73.98\), \(r = 0.625\).

05

MLE = least squares · ridge · robust regression

S10–S11 · B2 §7.3–7.5
WhatLinear regression \(t = \mathbf{w}^\top\boldsymbol\phi(\mathbf{x}) + \varepsilon\). Noise Gaussian maano to likelihood maximise karna = squared error minimise karna.
Why"Least squares kyun?" ka asli answer yahi hai. Ridge = overfitting control; robust = outliers se bachao.
When"Derive least squares from MLE", "normal equations", "ridge regression", "effect of outliers", "Huber / Laplace loss".
How\(\mathbf{w}_{\text{ML}} = (\boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\). Ridge: \((\lambda\mathbf{I} + \boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\). Robust: squared loss ki jagah \(|r|\) ya Huber.
With \(t = \mathbf{w}^\top\boldsymbol\phi(\mathbf{x}) + \varepsilon\), \(\varepsilon \sim \mathcal{N}(0, \beta^{-1})\), the log-likelihood is \[\begin{aligned}\ln p(\mathbf{t}\mid\mathbf{w},\beta) &= \frac{N}{2}\ln\beta - \frac{N}{2}\ln 2\pi - \beta E_D(\mathbf{w}),\\ E_D(\mathbf{w}) &= \frac12\sum_{n=1}^{N}\big(t_n - \mathbf{w}^\top\boldsymbol\phi_n\big)^2,\end{aligned}\] so maximum likelihood ≡ least squares: \(\mathbf{w}_{\text{ML}} = (\boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\) (the normal equations) and \(\frac{1}{\beta_{\text{ML}}} = \frac1N\sum_n (t_n - \mathbf{w}_{\text{ML}}^\top\boldsymbol\phi_n)^2\). Ridge regression minimises \(E_D(\mathbf{w}) + \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2\), giving \(\mathbf{w} = (\lambda\mathbf{I} + \boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\). Robust regression uses heavy-tailed noise (Laplace → absolute loss, or the Huber loss) so that outliers have bounded influence.
Huber: \(L_\delta(r) = \tfrac12 r^2\) for \(|r| \le \delta\), else \(\delta|r| - \tfrac12\delta^2\). Quadratic near 0, linear in the tails, so one outlier cannot dominate.
Intercept \(w_0\) ko ridge penalty mat do (data centre karo, ya penalty matrix mein \(w_0\) ka entry 0 rakho). Warna sab predictions zero ki taraf shrink honge.
Ridge se pehle features standardise karo. Warna penalty unit pe depend karegi (CGPA vs attendance %).
Target: end-semester SGPA. OLS (normal equations, matches sklearn exactly) \(R^2 = 0.790\); Ridge (\(\alpha\) by CV) \(R^2 = 0.798\) best. Robustness test: corrupt 8 % of training targets → OLS test RMSE \(0.668 \to 0.839\), Huber \(0.678 \to 0.675\) (barely moves).

W2 · Show that maximising the Gaussian likelihood is the same as minimising the sum-of-squares error.

Show solution

06

Bayesian linear regression

S11 · B1 §3.3, B2 §7.6
What\(\mathbf{w}\) ko ek number nahi, ek distribution maano. Prior \(\mathcal{N}(\mathbf{0},\alpha^{-1}\mathbf{I})\) × likelihood → posterior \(\mathcal{N}(\mathbf{m}_N,\mathbf{S}_N)\).
WhyPrediction ke saath uncertainty milti hai ("SGPA 6.1 ± 1.4"). Overfitting automatically kam (prior = regulariser).
When"Derive posterior over \(\mathbf{w}\)", "predictive distribution", "relation between MAP and ridge", "evidence approximation".
How\(\mathbf{S}_N^{-1} = \alpha\mathbf{I} + \beta\boldsymbol\Phi^\top\boldsymbol\Phi\), \(\mathbf{m}_N = \beta\mathbf{S}_N\boldsymbol\Phi^\top\mathbf{t}\). Predict: mean \(\mathbf{m}_N^\top\boldsymbol\phi\), variance \(\frac1\beta + \boldsymbol\phi^\top\mathbf{S}_N\boldsymbol\phi\).
In Bayesian linear regression a Gaussian prior \(p(\mathbf{w}) = \mathcal{N}(\mathbf{w}\mid\mathbf{0},\alpha^{-1}\mathbf{I})\) combined with the Gaussian likelihood gives the posterior \(p(\mathbf{w}\mid\mathbf{t}) = \mathcal{N}(\mathbf{w}\mid\mathbf{m}_N,\mathbf{S}_N)\) with \[\mathbf{S}_N^{-1} = \alpha\mathbf{I} + \beta\boldsymbol\Phi^\top\boldsymbol\Phi, \qquad \mathbf{m}_N = \beta\,\mathbf{S}_N\boldsymbol\Phi^\top\mathbf{t}.\] The predictive distribution is \(p(t\mid\mathbf{x},\mathbf{t}) = \mathcal{N}\big(t\mid\mathbf{m}_N^\top\boldsymbol\phi(\mathbf{x}),\,\sigma_N^2(\mathbf{x})\big)\) with \(\sigma_N^2(\mathbf{x}) = \frac{1}{\beta} + \boldsymbol\phi(\mathbf{x})^\top\mathbf{S}_N\boldsymbol\phi(\mathbf{x})\): noise plus parameter uncertainty. The posterior mode equals the ridge solution with \(\lambda = \alpha/\beta\).
Predictive variance ke do parts: \(1/\beta\) = data ka noise (kabhi kam nahi hoga), \(\boldsymbol\phi^\top\mathbf{S}_N\boldsymbol\phi\) = model ki uncertainty (data badhne se \(\to 0\)).
MAP estimate Bayesian nahi hai, woh sirf ridge hai. "Fully Bayesian" = poore posterior pe average karke predict karna.
Implemented from scratch with evidence maximisation: \(\alpha = 0.289\), \(\beta = 2.27\) (noise \(\sigma = 0.66\) SGPA), effective parameters \(\gamma = \sum_i \frac{\lambda_i}{\alpha + \lambda_i} = 15.98\) of 16. 93 % of test students fall inside the 95 % predictive band: the uncertainty is honest.

Kernel functions · kernel trick · support vector machines

S15–S16 · B2 §14.2–14.5
WhatKernel \(k(\mathbf{x},\mathbf{x}') = \boldsymbol\phi(\mathbf{x})^\top\boldsymbol\phi(\mathbf{x}')\): high-dimensional features ka dot product, bina \(\boldsymbol\phi\) banaye. SVM = maximum-margin linear classifier jo kernels use karta hai.
WhyLinear method → nonlinear boundary, cheap mein. SVM 10-mark ka classic: margin, support vectors, soft margin, kernel trick.
When"Explain kernel trick with example", "Mercer condition", "hard vs soft margin", "support vectors", "role of \(C\) and \(\gamma\)".
HowAlgorithm ko dot products mein likho (dual), phir \(\mathbf{x}^\top\mathbf{z}\) ki jagah \(k(\mathbf{x},\mathbf{z})\). SVM: \(\max \frac{2}{\lVert\mathbf{w}\rVert}\) s.t. \(t_n(\mathbf{w}^\top\boldsymbol\phi_n + b) \ge 1\).
A kernel is a function \(k(\mathbf{x},\mathbf{x}') = \boldsymbol\phi(\mathbf{x})^\top\boldsymbol\phi(\mathbf{x}')\) that computes an inner product in a feature space; it is valid (Mercer) if every Gram matrix \(K_{nm} = k(\mathbf{x}_n,\mathbf{x}_m)\) is positive semidefinite. The kernel trick replaces every inner product in an algorithm written in dual form by \(k(\cdot,\cdot)\). A support vector machine finds the separating hyperplane with maximum margin \(2/\lVert\mathbf{w}\rVert\): \[\min_{\mathbf{w},b,\boldsymbol\xi}\; \frac12\lVert\mathbf{w}\rVert^2 + C\sum_{n}\xi_n \quad\text{s.t.}\quad t_n\big(\mathbf{w}^\top\boldsymbol\phi(\mathbf{x}_n) + b\big) \ge 1 - \xi_n,\;\; \xi_n \ge 0,\] (hard margin: all \(\xi_n = 0\)). Only the support vectors (points on or inside the margin) have non-zero dual coefficients, and \(f(\mathbf{x}) = \sum_n a_n t_n k(\mathbf{x},\mathbf{x}_n) + b\).
RBF kernel \(k(\mathbf{x},\mathbf{x}') = \exp(-\gamma\lVert\mathbf{x}-\mathbf{x}'\rVert^2)\): \(\gamma\) bada → har point ka influence chhota → wiggly boundary (overfit). \(C\) bada → margin violations mehngi → hard margin (overfit). Dono validation se tune karo.
"Kernel trick = data ko higher dimension mein map karna" adhoora answer hai. Point ye hai ki mapping explicitly compute nahi hoti; sirf \(k(\mathbf{x},\mathbf{z})\) compute hota hai.
Linear, RBF and polynomial SVMs compared: CV AUC 0.949 / 0.939 / 0.915. RBF grid search picked \(C = 10\), \(\gamma = 0.003\). Small \(\gamma\) means a nearly linear boundary, consistent with linear models doing just as well on this data.

K-Means clustering

S19 · B1 §9.1
WhatData ko \(K\) groups mein baanto: har point apne nearest centroid ka; centroid = apne points ka mean. Repeat till nothing changes.
WhySabse common clustering algorithm, aur EM ka "hard" version. 10-mark numerical trace almost guaranteed.
When"Apply K-means to the data with initial centroids…", "explain the algorithm", "choose \(K\)", "limitations".
How(1) init \(\boldsymbol\mu_k\), (2) assign \(\mathbf{x}_n \to \arg\min_k \lVert\mathbf{x}_n - \boldsymbol\mu_k\rVert^2\), (3) \(\boldsymbol\mu_k\) = mean of its points, (4) repeat. \(J\) kabhi badhta nahi.
K-Means partitions \(N\) points into \(K\) clusters by minimising the distortion \[J = \sum_{n=1}^{N}\sum_{k=1}^{K} r_{nk}\,\lVert\mathbf{x}_n - \boldsymbol\mu_k\rVert^2, \qquad r_{nk}\in\{0,1\}.\] It alternates an assignment step (\(r_{nk} = 1\) for the nearest centroid, minimising \(J\) w.r.t. \(r\)) and an update step \(\boldsymbol\mu_k = \dfrac{\sum_n r_{nk}\mathbf{x}_n}{\sum_n r_{nk}}\) (minimising \(J\) w.r.t. \(\boldsymbol\mu\)). Each step cannot increase \(J\), so the algorithm converges, but only to a local minimum that depends on initialisation.
\(K\) choose karne ke 3 tareeke: elbow (\(J\) vs \(K\) ka "kink"), silhouette (max), aur GMM ka BIC (min). Initialisation ke liye k-means++ (door wale points ko seed banao) + multiple restarts.
K-Means spherical, equal-size clusters assume karta hai aur outliers pe mean kheench jaata hai. Features scale karo pehle (StandardScaler), warna attendance (0–100) CGPA (0–10) ko dominate karega.
From-scratch K-Means (k-means++ seeding, Lloyd iterations, 24 iterations to converge) on 15 standardised features, \(k = 3\), scratch vs sklearn ARI 0.86. Personas: High risk (111 students, 74 % at risk), Coasting (129, 9 %), Engaged achievers (160, 11 %). Silhouette 0.166: risk is a continuum, not separate blobs.

S20–S21 · B1 §9.2–9.4
WhatData = \(K\) Gaussians ka weighted mix. Har point ko soft membership (responsibility \(\gamma\)) milti hai, hard 0/1 nahi.
WhyHidden variable wale har model (GMM, HMM, factor analysis) ka training EM se hota hai. Unit 3 + Unit 4 dono mein kaam aata hai.
When"Explain EM with example", "derive E and M steps for GMM", "K-Means vs GMM", "why EM increases likelihood".
HowE-step: \(\gamma_{nk} = \dfrac{\pi_k\mathcal{N}(\mathbf{x}_n\mid\boldsymbol\mu_k,\boldsymbol\Sigma_k)}{\sum_j \pi_j\mathcal{N}(\mathbf{x}_n\mid\boldsymbol\mu_j,\boldsymbol\Sigma_j)}\). M-step: weighted means, covariances, \(\pi_k = N_k/N\). Repeat.
A Gaussian mixture is \(p(\mathbf{x}) = \sum_{k=1}^{K}\pi_k\,\mathcal{N}(\mathbf{x}\mid\boldsymbol\mu_k,\boldsymbol\Sigma_k)\) with \(0 \le \pi_k \le 1\), \(\sum_k\pi_k = 1\). The EM algorithm maximises the likelihood of models with latent variables by alternating the E-step, which computes the responsibilities \(\gamma(z_{nk})\) under the current parameters, and the M-step: \[\begin{aligned}N_k &= \sum_n\gamma_{nk}, & \boldsymbol\mu_k &= \frac{1}{N_k}\sum_n\gamma_{nk}\mathbf{x}_n,\\ \pi_k &= \frac{N_k}{N}, & \boldsymbol\Sigma_k &= \frac{1}{N_k}\sum_n\gamma_{nk}(\mathbf{x}_n-\boldsymbol\mu_k)(\mathbf{x}_n-\boldsymbol\mu_k)^\top.\end{aligned}\] In the general view, EM maximises \(\mathcal{Q}(\boldsymbol\theta,\boldsymbol\theta^{\text{old}}) = \mathbb{E}_{\mathbf{Z}\mid\mathbf{X},\boldsymbol\theta^{\text{old}}}\big[\ln p(\mathbf{X},\mathbf{Z}\mid\boldsymbol\theta)\big]\), and each iteration is guaranteed not to decrease \(\ln p(\mathbf{X}\mid\boldsymbol\theta)\).

S22–S23 · B2 §12.1–12.3
WhatPCA: data ko un directions pe project karo jahan variance sabse zyada hai (covariance ke eigenvectors). FA: observed features = few hidden factors + noise.

S24–S25 · B2 §25.1, 25.5
WhatClustering "close" ko kaise naapta hai (distance), clusters achhe hain ya nahi kaise bataate hain (metrics), aur tree-style clustering (dendrogram).
WhyHierarchical ko \(K\) pehle se nahi chahiye; dendrogram dekh ke cut karo. Linkage ka difference 5-mark compare question hai.

HowAgglomerative: har point alag cluster → closest pair merge → distance update (linkage rule) → repeat. Dendrogram ko ek height pe cut karo.
Agglomerative hierarchical clustering starts with each point as a cluster and repeatedly merges the two closest clusters, where closeness is the linkage: \[\begin{aligned}d_{\text{single}}(A,B) &= \min_{a\in A,\,b\in B} d(a,b), & d_{\text{complete}}(A,B) &= \max_{a\in A,\,b\in B} d(a,b),\\ d_{\text{avg}}(A,B) &= \frac{1}{|A|\,|B|}\sum_{a\in A}\sum_{b\in B} d(a,b),\end{aligned}\] and Ward merges the pair with the smallest increase in within-cluster variance. The merge history is drawn as a dendrogram; cutting it at a height gives a flat clustering. Clusterings are evaluated internally, e.g. the silhouette \(s(i) = \dfrac{b(i) - a(i)}{\max\{a(i), b(i)\}}\), Davies–Bouldin, Calinski–Harabasz, or externally against known labels (adjusted Rand index, NMI, purity).

When"Define HMM and its parameters", "three problems of HMM", "probability of a state sequence", "Markov assumption".
How\(\lambda = (\boldsymbol\pi, \mathbf{A}, \mathbf{B})\): \(\boldsymbol\pi\) = start probs, \(\mathbf{A}\) = state→state, \(\mathbf{B}\) = state→observation. Rows of \(\mathbf{A}\), \(\mathbf{B}\) sum to 1.
A first-order Markov chain satisfies \(p(z_t\mid z_1,\dots,z_{t-1}) = p(z_t\mid z_{t-1})\), described by \(\boldsymbol\pi\) and a transition matrix \(A_{jk} = p(z_t = k\mid z_{t-1} = j)\). A hidden Markov model adds observations generated from the hidden state by emission probabilities \(B_k(x) = p(x_t\mid z_t = k)\), so that \[p(\mathbf{X},\mathbf{Z}\mid\lambda) = p(z_1)\prod_{t=2}^{T}p(z_t\mid z_{t-1})\prod_{t=1}^{T}p(x_t\mid z_t).\] The three basic problems are evaluation \(p(\mathbf{X}\mid\lambda)\) (forward algorithm), decoding \(\arg\max_{\mathbf{Z}} p(\mathbf{Z}\mid\mathbf{X})\) (Viterbi) and learning \(\lambda\) (Baum–Welch / EM).
State \(k\) mein rehne ka expected time \(= \dfrac{1}{1 - A_{kk}}\) (geometric distribution). \(A_{kk} = 0.8\) → average 5 steps.
Markov model mein state dikhta hai; hidden Markov model mein nahi. "HMM mein emission matrix kyun?": kyunki observation state ka noisy signal hai.
Hidden states Struggling / Stable / Strong, observations = SGPA band of each completed semester (Poor \(\lt 6.5\), Average \(\lt 8\), Good \(\ge 8\)). Learned \(P(\text{stay Struggling}) = A_{11} = \mathbf{0.84}\): expected \(\frac{1}{1-0.84} \approx 6\) semesters in that state if nothing changes. That number is the case for intervening early.

Forward–backward · sum-product · scaling · maximum likelihood (Baum–Welch)

S30–S33 · B1 §13.2.2–13.2.4
WhatForward \(\alpha_t(k) = P(x_{1:t}, z_t = k)\). Backward \(\beta_t(k) = P(x_{t+1:T}\mid z_t = k)\). Dono milake \(\gamma\) (har time pe state probability) aur \(\xi\) (transitions).
WhySaare \(K^T\) paths enumerate karna impossible; forward–backward \(O(K^2T)\) mein kar deta hai. Baum–Welch training inhi pe chalta hai.
When"Compute \(P(O\mid\lambda)\) by the forward algorithm", "explain backward variable", "why scaling?", "Baum–Welch re-estimation".
How\(\alpha_1 = \pi_k b_k(x_1)\); \(\alpha_t(k) = \big[\sum_j\alpha_{t-1}(j)A_{jk}\big]b_k(x_t)\). \(\beta_T = 1\). \(P(O) = \sum_k\alpha_T(k)\). \(\gamma = \alpha\beta/P(O)\).
The forward–backward algorithm computes, in \(O(K^2T)\), \[\begin{aligned}\alpha_t(k) &= \Big[\sum_{j}\alpha_{t-1}(j)\,A_{jk}\Big]\,b_k(x_t),\\ \beta_t(j) &= \sum_{k} A_{jk}\,b_k(x_{t+1})\,\beta_{t+1}(k),\end{aligned}\] giving \(p(\mathbf{X}) = \sum_k\alpha_T(k)\), the state posteriors \(\gamma_t(k) = \dfrac{\alpha_t(k)\beta_t(k)}{p(\mathbf{X})}\) and the pairwise posteriors \(\xi_t(j,k) = \dfrac{\alpha_t(j)A_{jk}b_k(x_{t+1})\beta_{t+1}(k)}{p(\mathbf{X})}\). It is the sum-product algorithm on the HMM chain. Because \(\alpha\) shrinks geometrically it is normalised at each step by scaling factors \(c_t\), with \(\ln p(\mathbf{X}) = \sum_t \ln c_t\). Baum–Welch is EM for HMMs: \[\pi_k = \gamma_1(k), \qquad A_{jk} = \frac{\sum_{t=1}^{T-1}\xi_t(j,k)}{\sum_{t=1}^{T-1}\gamma_t(j)}, \qquad B_k(v) = \frac{\sum_{t:\,x_t = v}\gamma_t(k)}{\sum_{t}\gamma_t(k)}.\]
Forward trellis for the worked example, \(O = (\text{Poor}, \text{Good}, \text{Poor})\). Each node shows \(\alpha_t(k)\); \(P(O) = 0.06264 + 0.01948 = 0.08212\).
Sum-product (forward–backward) mein \(\sum\) hota hai: sab paths ka total. Max-sum (Viterbi) mein \(\sum\) ki jagah \(\max\): sirf best path. Same skeleton, ek operator ka fark.
Long sequences pe \(\alpha\) underflow karke 0 ho jaata hai (\(0.1^{100}\)). Isliye scaling factors ya log-space. Exam line: "to prevent numerical underflow while keeping \(\ln p(\mathbf{X}) = \sum_t \ln c_t\)".
Scaled forward–backward + Baum–Welch from scratch, vectorised over sequences of equal length. Log-likelihood \(-1210.044\) = hmmlearn's exactly with the same parameters; converged in 67 iterations. Learned \(\mathbf{A}\) is within 0.063 of the generator's true \(\mathbf{A}\). BIC over \(K = 2\dots5\) picks \(K = 3\).

Viterbi decoding

S33 · B1 §13.2.5
WhatObservations diye hain; sabse likely poora hidden-state path kaunsa hai? Dynamic programming se, \(\sum\) ki jagah \(\max\).
Why"Is student ka hidden academic state har semester kya tha?" Speech recognition, POS tagging, sab Viterbi hai. 10-mark trace favourite.
When"Find the most probable state sequence", "explain Viterbi with backtracking", "Viterbi vs forward".
How\(\delta_1 = \pi_k b_k(x_1)\); \(\delta_t(k) = \max_j[\delta_{t-1}(j)A_{jk}]\,b_k(x_t)\), store \(\psi_t(k) = \arg\max_j\). End: best final state, then follow \(\psi\) backwards.
The Viterbi algorithm finds \(\mathbf{Z}^\star = \arg\max_{\mathbf{Z}} p(\mathbf{Z}\mid\mathbf{X})\) by dynamic programming: \[\delta_t(k) = \Big[\max_{j}\,\delta_{t-1}(j)\,A_{jk}\Big]\,b_k(x_t), \qquad \psi_t(k) = \arg\max_{j}\,\delta_{t-1}(j)\,A_{jk},\] and the path is recovered by backtracking from \(z_T^\star = \arg\max_k\delta_T(k)\), \(z_{t}^\star = \psi_{t+1}(z_{t+1}^\star)\). It is the max-sum algorithm on the chain, usually run in log space; cost \(O(K^2T)\).
Viterbi path ≠ most likely state at each step. In the example below, posterior decoding (\(\arg\max_k\gamma_t(k)\)) gives S, G, S, but the single best path is S, S, S, because the jumps S → G → S are expensive under \(\mathbf{A}\).
Viterbi in log space from scratch: decoded paths agree with hmmlearn on 100 % of semesters and recover the generator's true hidden state 92.5 % of the time (vs 92.0 % by reading the band directly). On a "declining" student the filtered \(P(\text{Struggling})\) jumps from \(\approx 0\) to 0.68 in the semester the grades drop.

Linear dynamical systems · the Kalman filter

S34 · B1 §13.3
WhatHMM jaisa hi, lekin hidden state continuous hai aur sab kuch linear + Gaussian. Example: student ka "true ability level" jo dheere badalta hai.
WhyTracking, GPS, smoothing noisy sensors, SGPA forecasting. Kalman filter = forward algorithm for continuous states.
When"Explain LDS / state-space model", "Kalman predict and update equations", "compare LDS with HMM".
HowPredict: \(\mathbf{m}^- = \mathbf{A}\mathbf{m}\), \(\mathbf{P}^- = \mathbf{A}\mathbf{P}\mathbf{A}^\top + \boldsymbol\Gamma\). Update: \(\mathbf{K}\), then \(\mathbf{m} = \mathbf{m}^- + \mathbf{K}(\mathbf{y} - \mathbf{C}\mathbf{m}^-)\).
A linear dynamical system has a continuous latent state with \[\mathbf{z}_t = \mathbf{A}\mathbf{z}_{t-1} + \mathbf{w}_t,\;\; \mathbf{w}\sim\mathcal{N}(\mathbf{0},\boldsymbol\Gamma), \qquad \mathbf{x}_t = \mathbf{C}\mathbf{z}_t + \mathbf{v}_t,\;\; \mathbf{v}\sim\mathcal{N}(\mathbf{0},\boldsymbol\Sigma).\] Because everything is linear-Gaussian, the filtered posterior \(p(\mathbf{z}_t\mid\mathbf{x}_{1:t})\) stays Gaussian and is computed exactly by the Kalman filter: \[\begin{aligned}\mathbf{P}_t^- &= \mathbf{A}\mathbf{P}_{t-1}\mathbf{A}^\top + \boldsymbol\Gamma, & \mathbf{K}_t &= \mathbf{P}_t^-\mathbf{C}^\top\big(\mathbf{C}\mathbf{P}_t^-\mathbf{C}^\top + \boldsymbol\Sigma\big)^{-1},\\ \mathbf{m}_t &= \mathbf{A}\mathbf{m}_{t-1} + \mathbf{K}_t\big(\mathbf{x}_t - \mathbf{C}\mathbf{A}\mathbf{m}_{t-1}\big), & \mathbf{P}_t &= (\mathbf{I} - \mathbf{K}_t\mathbf{C})\mathbf{P}_t^-.\end{aligned}\] \(\mathbf{K}_t\) is the Kalman gain. The LDS is the continuous-state analogue of the HMM; its parameters are learned with EM and its smoother is the Rauch–Tung–Striebel recursion.

Unit 1 · probability

  • Independent \(P(A,B) = P(A)P(B)\); cond. indep. \(P(A,B\mid C) = P(A\mid C)P(B\mid C)\)

  • Quantile \(F^{-1}(q)\); \(z = (x-\mu)/\sigma\)
  • \(E = \tfrac12\sum(y-t)^2\), \(E_{\text{RMS}} = \sqrt{2E/N}\), regularised \(+\frac{\lambda}{2}\lVert\mathbf{w}\rVert^2\)

Unit 2 · linear models

  • \(\mathbf{w}_{\text{ML}} = (\boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\); \(\;\beta_{\text{ML}}^{-1}\) = mean squared residual
  • Ridge \((\lambda\mathbf{I} + \boldsymbol\Phi^\top\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\mathbf{t}\) = MAP of BLR with \(\lambda = \alpha/\beta\)
  • BLR \(\mathbf{S}_N^{-1} = \alpha\mathbf{I} + \beta\boldsymbol\Phi^\top\boldsymbol\Phi\), \(\mathbf{m}_N = \beta\mathbf{S}_N\boldsymbol\Phi^\top\mathbf{t}\), \(\sigma^2(\mathbf{x}) = \frac1\beta + \boldsymbol\phi^\top\mathbf{S}_N\boldsymbol\phi\)
  • \(y = \mathbf{w}^\top\mathbf{x} + w_0\); boundary distance \(-w_0/\lVert\mathbf{w}\rVert\)
  • Logistic \(p(C_1\mid\boldsymbol\phi) = \sigma(\mathbf{w}^\top\boldsymbol\phi)\), \(\sigma(a) = \frac{1}{1+e^{-a}}\)

Unit 3 · mixtures & clustering

  • EM never decreases \(\ln p(\mathbf{X}\mid\boldsymbol\theta)\); local optimum only
  • PCA: \(\mathbf{S}\mathbf{u}_i = \lambda_i\mathbf{u}_i\); explained \(\lambda_i/\sum_j\lambda_j\); keep \(k\) for \(\ge 90\%\)

  • Linkage: single \(\min\) · complete \(\max\) · average mean · Ward \(\Delta\)variance
  • \(s = \dfrac{b-a}{\max(a,b)}\in[-1,1]\); \(\text{BIC} = -2\ln L + p\ln N\) (lower better)

Unit 4 · HMM & LDS

  • \(\lambda = (\boldsymbol\pi,\mathbf{A},\mathbf{B})\); params \((K-1) + K(K-1) + K(M-1)\)
  • \(\alpha_1(k) = \pi_k b_k(x_1)\), \(\alpha_t(k) = \big[\sum_j\alpha_{t-1}(j)A_{jk}\big]b_k(x_t)\), \(P(O) = \sum_k\alpha_T(k)\)
  • \(\beta_T = 1\), \(\beta_t(j) = \sum_k A_{jk}b_k(x_{t+1})\beta_{t+1}(k)\)
  • \(\gamma_t = \frac{\alpha_t\beta_t}{P(O)}\); \(\xi_t(j,k) = \frac{\alpha_t(j)A_{jk}b_k(x_{t+1})\beta_{t+1}(k)}{P(O)}\)
  • BW: \(\pi = \gamma_1\); \(A_{jk} = \frac{\sum_t\xi_t(j,k)}{\sum_t\gamma_t(j)}\); \(B_k(v) = \frac{\sum_{x_t=v}\gamma_t(k)}{\sum_t\gamma_t(k)}\)
